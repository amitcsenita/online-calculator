How to use the Daily Planner

The Daily Planner is a 24-hour schedule you fill in, reflect on, and review — all in one page. Sign in once and everything saves automatically to the cloud.

1

Navigating dates

The planner opens on today. Use the arrows or the date picker to view any other day.

  • ←
    Go to the previous day

    Click the ← arrow button on the left of the date header to move back one day. The header changes from Today to Yesterday, then shows the weekday name for earlier dates.

  • →
    Go to the next day

    Click the → arrow button on the right to move forward one day. From today, it shows Tomorrow; one more click shows the weekday name.

  • 📅
    Jump to any date

    Use the date input on the far right of the header to pick any date from the calendar. The grid and all other sections update immediately.

Date header format: For today, yesterday, and tomorrow the header reads Today · Thursday · 28 May 2026. For dates further away only the weekday name and full date appear — no · prefix.
2

Managing tasks

The schedule shows 24 hour slots. Each slot holds one task. Tasks save automatically — no Save button needed.

  • +
    Add a task

    Click the + add task hint inside any hour row. A text input appears, along with a category selector and priority control. Type your task, then press Enter or click away to save.

    Pressing Escape while the input is empty cancels without creating a task.

  • 🏷
    Set a category

    While the input is open, use the category dropdown to label the task. Available categories:

    General Work Personal Health

    The badge appears on the saved task and is used by the category filter.

  • ↑
    Set a priority

    While the input is open, use the priority control (Low / Normal / High) to flag urgency. High-priority tasks get an ↑ badge and a coloured left border so they stand out in the grid.

  • ✓
    Mark a task done

    Click the circle button on the right of the row to toggle completion.

    ✓→ incomplete ✓→ done

    Completed tasks show strikethrough text. The progress bar and task counter (1 / 3 done) update immediately. Clicking the button again un-completes the task.

  • ✏
    Edit a task

    Click the task text to re-open the edit input. The text is pre-filled. Change it and click away to save. Click the × cancel button to discard the edit and restore the original text.

  • 🗑
    Delete a task

    Click the task text to open edit mode, then click the red Del button. The row immediately reverts to the + add task state and the counter resets.

Auto-save: Every change — create, edit, complete, delete — is sent to the server automatically. You never need to press a Save button.
3

Filtering the schedule

Use the filter bar above the hour grid to focus on the rows that matter right now. Filters combine: you can narrow by hours and category at the same time.

  • ⏱
    Filter by hour range

    Click any pill in the Hours row to show only rows in that window:

    All 6–22 9–18 Morning Afternoon Evening

    Click All at any time to restore all 24 rows. The active pill is highlighted in dark.

  • 🏷
    Filter by category

    Click one or more pills in the Category row to show only tasks with those labels. Multiple categories can be active at the same time — rows matching any active category remain visible.

    Click an active category pill again to deactivate it.

  • ↑
    Filter by priority

    Click ↑ High, — Normal, or ↓ Low in the Priority row to see only tasks at that urgency level.

Empty state: If every visible task is filtered out, the grid shows "No tasks match the active filters." Remove a filter pill to bring rows back.
4

Daily reflection

At the end of the day, score how it went and write a short note. Everything saves automatically when you click away from a field.

  • A
    Grade the day

    Click a letter grade under "How did the day go?" to record an overall score for the day.

    A+ A B C D F

    Only one grade is active at a time. Clicking the active grade deselects it. The grade appears in the Analytics section immediately.

  • ●
    Rate Focus, Energy, and Mood

    Each self-check row has 5 dot buttons. Click a dot to set the score to that number (filled dots = score). Click the same dot again to lower the score by 1.

    = 3 / 5

    Scores are saved and shown as individual numbers in the Analytics Today tab.

  • 📝
    Write your reflection notes

    Three text areas capture your day in words:

    • Wins — what went well, highlights to remember
    • Could be better — what didn't go to plan or slowed you down
    • Lessons & notes — one thing learned, one thing to carry forward

    Type freely. The status line shows saving… while you type and saved HH:MM once the note is confirmed. Each textarea saves independently when you click away.

Save indicator: Watch the small status text next to the Reflection label. Green saved 14:32 means your entry is safely stored.
5

Analytics

The Analytics section sits below Reflection and shows stats for today, this week, or the last 28 days.

  • 📊
    Today tab

    Open by default. Shows six stat boxes that update live as you work:

    2/5Done
    40%Complete
    AGrade
    4Focus
    3Energy
    5Mood

    A by-category breakdown bar appears once at least one task exists, showing how your time is split across categories.

  • 📅
    This Week tab

    Click This Week to see a bar chart for the 7 days of the current week. Each column shows tasks done vs. pending for that day. Today is highlighted. Click a column to jump the planner to that day.

  • 🗓
    28 Days tab

    Click 28 Days to see a heatmap calendar for the last four weeks. Cells are shaded from light green (few tasks) to dark green (many tasks). Today has an accent outline. Click any filled cell to jump to that day.

Switching tabs: Click any tab label (Today / This Week / 28 Days) to switch views. Click Today again to return to the live stats.
